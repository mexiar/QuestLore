# QuestLore 0.17.4

## Localized interface

- Complete interface support for **English, Latin American Spanish, French, German and Brazilian Portuguese**: settings, tracker headings, tooltips, history, loading messages and key bindings.
- Choose the **interface language separately from the summary language**, with both preferences saved per character.
- Automatically detect supported game languages for the interface, with English as the fallback. Preserve existing manual language preferences when upgrading.
- Update interface text immediately when switching languages, including the history category.
- Improve wrapping and spacing for longer translated labels, buttons and the **Read full quest text** action.
- Localize descriptions in the AddOns list. Quest titles and original quest text continue to use the game client's language.

## Narrative improvements included from 0.17.2–0.17.3

- Revise **34 English narratives** against recovered, validated original Forever quest descriptions and objectives, and update their **102 French, German and Portuguese versions**.
- Update **404 Latin American Spanish narratives** directly from original esMX quest data: **35 rewritten stories** and **369 additional name corrections**.
- Add or correct **4,055 Spanish** and **six English** fallback quest titles from validated client records.
- Correct changed assignments, localized character names and ambiguous references to families, wells and ships. Keep summaries focused on the current quest step, without later chain spoilers.
- Preserve differences between English and Spanish originals. Missing or unvalidated descriptions are not treated as complete sources.

All **5,259 quest summaries per supported language** remain bundled locally. No online AI or translation service runs during play.
